# Dataset

## Description

This project uses fictional employee data from Kaggle. The analysis does not represent IBM's actual workforce or employment practices.


## Data Source

- Dataset: [IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
- Original Creator: IBM Data Scientists
- Published by: pavansubhasht
- Platform: Kaggle
- Data Type: Fictional Data

## Data Structure

- File Name: WA_Fn-UseC_-HR-Employee-Attrition.csv
- File Format: CSV
- Number of Records: 1,470
- Number of Columns: 35
- Granularity: One record per employee
- Primary Identifier: EmployeeNumber
- Target Variable: Attrition


## Download Instructions

1. Access the dataset page on Kaggle.
2. Download the dataset.
3. Extract the CSV file.
4. Save the original CSV file in `data/raw/`.

## Limitations

- The dataset contains fictional employee data.
- The dataset may not reflect real-world workforce characteristics.
- The dataset does not provide longitudinal information.
- Observed relationships do not establish causality.
- The findings should not be generalised to actual organisations without further validation.
